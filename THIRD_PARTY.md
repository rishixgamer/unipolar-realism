A public GitHub repository can be forked through GitHub's platform functionality, but absence of an explicit software license means you should **not assume** broad rights to redistribute a derivative standalone release.

Before publishing this project with upstream code/assets:

1. ask the UNIPOLAR author for explicit licensing/permission;
2. identify which files/assets were themselves derived from other mods;
3. preserve attribution requirements;
4. replace or exclude content for which redistribution rights are unclear.

This repository intentionally does not add a license over upstream material. Choose a license for **new original code** only after upstream/third-party boundaries are clear.

# MON-001 — Central-bank policy-rate reaction function

**Status:** draft research placeholder.

This document intentionally does **not** establish the final mechanic. It is the first example of the research → specification → implementation workflow.

## Research questions

1. Which central-bank mandate/regime is being modeled for a given country and period?
2. Which observable variables enter the decision process?
3. Is a Taylor-style rule being used descriptively, normatively, or merely as a tractable approximation?
4. How should expectations, interest-rate smoothing, the effective lower bound, unconventional policy, and regime changes be represented?
5. Which parameters are estimated, externally calibrated, or scenario-defined?

## Required evidence before approval

- official central-bank documentation for the relevant institutional mandate;
- empirical literature on reaction functions for the country/period;
- historical policy-rate, inflation, and labor/output data;
- alternative specifications and sensitivity analysis.

## Victoria 3 mapping questions

Victoria 3 does not natively expose a complete monetary transmission mechanism. Any in-game mapping must therefore document which channels are represented by scripted effects/modifiers and which remain outside the engine.
